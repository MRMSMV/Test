# CandySky · Фонтаны · v56

Смешанный состав пересчитывается в отдельном потоке при замене товара: длины лент и узлов подбираются под реальные контактные формы. Одноразмерные нормы 23/25/30/45 см сохранены; возврат с фольги на собственный латекс возвращает штатные длины.

Расчёт можно отменить. Остальные композиции доступны; ошибка оставляет прежний фонтан. Переход плавный, физика остаётся свободной. После переноса шары могут менять соседей; дополнительных связей между шарами нет.

До 4 фонтанов и 100 шаров, в том числе пакет 40 под потолок. Старое сохранение v55 читается без изменения исходной базы. Для отката оставлена точная v55.

Проверены 20 смешанных составов с перемещением, 16 одноразмерных норм, обратные замены на всех базах, отмена/восстановление, мобильный интерфейс и сохранение 100 объектов. Подробные численные итоги — test-report-v56.json. Проверка относится к приближённым физическим оболочкам. Реальный iPhone/Safari и его скорость не проверены. Three.js/Rapier нужны с CDN; офлайн не готов.
