# CandySky 3D · v50

Конструктор воздушных шаров: https://mrmsmv.github.io/Test/?v=50

В управлении выбранной композиции появился «Цвет лент и узлов»: белый, розовый, красный, золотистый, серебристый и чёрный. У фонтана выбор меняет все ленты, видимые узлы, перехват и хвостики грузика. У отдельного шара — только его оформление; цвет шаров независим.

Ширина лент — 5 мм. Утверждённые размеры грузика, длины и физика сохранены. Старые сцены сохраняют прежние смешанные цвета до первого выбора. Выбранный цвет сохраняется при замене шаров, сбросе и перезагрузке.

Текущая сборка: candysky-rapier-lab-1-v50-ribbon-colors.html. Предыдущая для отката: candysky-rapier-lab-1-v49-silver-foil-weight.html.

Проверено в Chromium. Реальный iPhone/Safari ещё не проверен. Для загрузки Three.js/Rapier нужен интернет.
