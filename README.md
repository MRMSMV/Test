# CandySky 3D · v52

Конструктор воздушных шаров: https://mrmsmv.github.io/Test/?v=52

Добавлена четвёртая стена: изображение 2000×1200 целиком на 5×3 м, без обрезки и повторения. Стена видна изнутри комнаты; снаружи не перекрывает обзор. Она участвует в существующих отражениях.

Панорама остальных трёх стен, потолок, пол, физика и оформление шаров сохранены. Сохранения v51 импортируются вместе с цветами лент.

Текущая сборка: candysky-rapier-lab-1-v52-fourth-wall.html. Предыдущая для отката: candysky-rapier-lab-1-v51-greige-ceiling.html.
