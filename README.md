# CandySky 3D · v51

Конструктор воздушных шаров: https://mrmsmv.github.io/Test/?v=51

Матовый потолок Greige: изображение 2000×2000 целиком на 5×5 м, без повторения и обрезки. Высота комнаты 3 м. Потолок виден в существующих отражениях; вспомогательные панели размещаются внутри комнаты. Размер текстуры адаптируется к устройству.

Сохранения v50 импортируются, включая цвета лент. Физика, коллайдер потолка, шары, пол и стены сохранены.

Текущая сборка: candysky-rapier-lab-1-v51-greige-ceiling.html. Предыдущая для отката: candysky-rapier-lab-1-v50-ribbon-colors.html.

Проверено в Chromium. Реальный iPhone/Safari ещё не проверен. В диагностике отмечено потемнение хромового сердца после восстановления сохранения, воспроизводимое также в v50; этот отдельный дефект не заявляется исправленным здесь. Для Three.js/Rapier нужен интернет.
