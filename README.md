# CandySky · Фонтаны · v55

Под потолок можно добавить 40 шаров одним нажатием. Прежний предел 20 за одно добавление снят; действует общий лимит 100 шаров в комнате. Поле количества показывает максимум по оставшимся местам. Например, два фонтана по 15 и 40 потолочных шаров — 70 объектов.

Физика, модели, ленты, оформление комнаты и плотная сборка фонтанов v54 сохранены. Черновик v54 читается без изменения исходной базы. Для отката оставлена точная v54.

Проверены Chromium/Rapier и мобильная эмуляция: добавление 40, полная физика и ленты, сохранение 70/100 объектов, запрет превышения 100. Реальный iPhone/Safari не проверен. Three.js/Rapier загружаются с CDN; офлайн не готов.
