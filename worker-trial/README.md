# CandySky — проба физики в Web Worker

Отдельная проба рядом с v56: https://mrmsmv.github.io/Test/worker-trial/
Обычная v56: https://mrmsmv.github.io/Test/

Главный поток рисует сцену и обслуживает ввод; Rapier и XPBD ленты считаются в отдельном worker на 60 Гц. Подбор смешанного состава остаётся отдельным worker v56 и не стал мгновенным. Замена сохраняет старый состав до готового результата.

Сохранение отдельное: candysky-live-worker-trial-drafts, schema4. Черновик v56 не читается и не изменяется. Проба начинает с отдельной сцены.

Локально проверены четыре базы, движение, замена/reload, одиночные/потолочные и 4 фонтана + 40 потолочных (100 шаров). Численная сверка с v56 пройдена. Скорость и нагрев iPhone/Safari ещё не подтверждены. Новая версия основной сцены не выпускалась.
