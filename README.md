# CandySky 3D · v49

Конструктор воздушных шаров: https://mrmsmv.github.io/Test/?v=49

Утверждённый серебряный грузик в мятой фольге: основание около 8 см, общая высота около 10 см. Установлен у фонтанов и одиночных шаров с грузиком. Крепление ленты расположено на перехвате оболочки. Потолочные шары остаются свободными.

Грузики используют общую геометрию и индивидуальные отражения. Сохранения предыдущей сборки импортируются без изменения исходного черновика.

Текущая сборка: candysky-rapier-lab-1-v49-silver-foil-weight.html. Предыдущая для отката: candysky-rapier-lab-1-v48-single-ceiling-balloons.html.

Проверено в Chromium, включая сенсорное перетаскивание. Реальный iPhone/Safari ещё не проверен. Для загрузки Three.js и Rapier нужен интернет.
