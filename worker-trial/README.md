# CandySky — Worker, проба 3

Проба: https://mrmsmv.github.io/Test/worker-trial/
Обычная v56 для сравнения/отката: https://mrmsmv.github.io/Test/

Основной index и файлы v56/v55 не изменены. Сохранения пробы остаются в отдельной candysky-live-worker-trial-drafts, schema4.

В пробе 3 исправлено временное растяжение связей между ярусами при переносе грузика. После шага Rapier ограничивается только превышение максимальной длины связи, с допуском 0,1 мм. Корректируется вся дочерняя ветвь вместе, чтобы не растягивать присоединённые к ней ленты. Убирается относительная скорость, направленная на дальнейшее растяжение. Связь может провисать и поворачиваться; шары внутри ярусов не скреплены между собой. Перенос грузика для всех составов ограничен скоростью 2 м/с, с плавным разгоном и торможением.

Это изменение динамики в отдельной пробе. Геометрия, массы, подъёмные силы, каталожные объёмы и заданные длины прежние. Новая аэродинамика не включена. Сохраняются исправления и облегчение отображения из пробы 2: проверка последних параметров при подборе, обработка отказа worker, визуальные уровни детализации, кэш полноразмерных фактур и отрисовка по изменениям на паузе.

Локальные численные проверки: резкий перенос четырёх баз 23/25/30/45 см и фонтана с цифрой 6. В этих сценариях превышение длины связей между ярусами не более 0,1 мм. Проверки проводились в Chromium/Linux; поведение на реальном iPhone/Safari ещё требует пользовательской проверки. Это не замер FPS и не подтверждение полного совпадения динамики с v56.
