# CandySky · Фонтаны · v57

Ускорен пересчёт смешанных фонтанов. Удачные планы запоминаются в текущей вкладке, а при изменении готового смешанного фонтана сначала проверяется его текущая сборка. Каждый вариант проходит прежнюю полную проверку физики; если он не подходит, выполняется обычный поиск.

На четырёх локальных контролируемых сценариях выигрыш различался: сложный повтор 27 → 4,4 с, изменение готовой смешанной сборки 21 → 3,6 с. Это замеры прогретого worker на компьютере, без запуска worker/интерфейса; скорость iPhone не измерялась. Ускорение не гарантировано для каждого нового состояния сцены. Память очищается при перезагрузке или остановке расчётного worker.

Модели, материалы, нормы одноразмерных фонтанов и требования к физике сохранены. До 4 фонтанов и 100 шаров суммарно, включая 40 под потолок. Сохранение v56 читается без записи в исходную базу; v57 сохраняет изменения отдельно. Для отката оставлена точная v56.

Проверены перенос сохранений, новые сохранения/перезагрузка, мобильный интерфейс/память/отмена, очередь/ошибки и сцена со 100 шарами. Численные итоги — test-report-v57.json. Three.js/Rapier нужны с CDN; офлайн не готов.
