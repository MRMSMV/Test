# Долги CandySky 3D

## PHOTO-001 — фотореалистичный статичный кадр по кнопке

- **Статус:** возобновлено новым поручением пользователя; браузерная проба v47 реализована. Приёмка на реальном iPhone/Safari и окончательное утверждение качества остаются открытыми.
- **Цель:** кнопка в Test фиксирует текущую композицию и ракурс, выдаёт статичное изображение, позволяет скачать PNG и вернуться в 3D. Без генеративного ИИ.
- **Сохранённый результат:** утверждённая проба Blender с физическими тенями и исправленным пятном над сердцем; рабочий локальный прототип v46 в `local-render/` и архив `candysky-v46-local-render.zip`. Подтверждены настоящий рендер, скачивание, возврат, пауза, отмена и кеш. Прототип не опубликован и не означает готовность функции в Test.
- **Причина первой отсрочки:** локальная реализация требует Python и Blender; для сайта нужен отдельный вычислительный сервис или другой способ расчёта. GitHub Pages сам не запускает Blender. Вариант GitHub Actions обсуждался, но не реализован: остаются передача сцены, запуск/авторизация и доставка результата в интерфейс.
- **Браузерная ветка:** v47 использует WebGL 2 и отдельный контекст с реальными моделями/светом. Сервер/вход GitHub/установка программ не нужны. Подробности в browser-photo/README.md; совпадение с Blender не обещается.
- **Условия возврата к задаче:** отдельное поручение пользователя; определить приемлемые качество и время ожидания, проверить выбранный движок на реальном iPhone/Safari и типовых композициях. Сохранить количество/формы/цвета/размеры объектов и ракурс, читаемые физические тени, отсутствие артефактов, восстановление 3D без потери состояния. Не превращать обсуждённый браузерный вариант в обязательство без проверки.
- **Текущая проба:** Test — v47, отдельная v45 для отката. v46 только локальный архив/прототип. Облачные сервисы не создавались. Остаток долга — реальная мобильная приёмка, оценка скорости/качества и дальнейшие изменения по отзыву пользователя.
