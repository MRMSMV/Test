# CandySky v47 — браузерная проба «Фото»

Кнопка рассчитывает статичный кадр на видеочипе устройства через WebGL 2. Нет Blender, сервера вычислений, авторизации GitHub, генеративного ИИ или нейросетевого шумоподавления. GitHub Pages отдаёт только HTML/JS. Обычный 3D-режим основан на v45, Three.js 0.164.1 и прежнем Rapier.

## Использование

Выберите композицию и ракурс → **Фото** → дождитесь кадра → **Скачать PNG**. **Вернуться в 3D** или Escape отменяет незавершённый расчёт и возвращает прежнюю паузу. **Завершить сейчас** сохраняет результат после окончания полного текущего прохода; ранний кадр может быть шумнее. После готовности показывается PNG, вращение/редактирование недоступны до возврата.

Ограничение длинной стороны: 960 px на компьютере и 720 px в мобильном режиме. Цель — 128 и 64 прохода соответственно. Время зависит от видеочипа, сцены и браузера, не обещается в секундах. Для неподдерживаемого WebGL/float-буфера, ошибки загрузки или потери контекста есть возврат в обычный 3D. Вкладка в фоне не продолжает активный расчёт.

## Калибровка и устройство

Вычисляется отдельная копия настоящих геометрий/материалов/UV/цветов вершин и текущей камеры; физика, массы, размеры и состав не пересобираются. Отражения получают настоящих соседей и комнату, карты/световые карточки обычного 3D не экспортируются. Есть физические тени. Поверхности пола/стен и матовый потолок 3 м участвуют в лучах. Оба прямоугольных источника целиком внутри комнаты.

Свет, экспозиция, AgX, контраст и оттенок пола подбирались по утверждённой пользователем пробе Blender на тех же вершинах, позициях, цветах и камере. Это другой движок, побайтовое/попиксельное совпадение с Blender не обещается. Для скорости применяются 6 отражений, 8 прохождений прозрачности, фильтрация глянцевых непрямых лучей и ограничение единичной яркости 6. Карты складок преобразуются из bump в tangent normal на отдельной копии; источник v45 не меняется. Прозрачный латекс — приближение тонкой прозрачной оболочки.

Промежуточный вид имеет лёгкий математический фильтр. Готовый кадр: AgX → контраст с мягкими тенями → удаление одиночных ярких точек → обычный non-local means в отображаемом RGB. Фильтр не дорисовывает объекты и не использует обученную модель. Он уменьшает зерно; очень ранний кадр не заменяет полный расчёт. WebGL-ресурсы фото освобождаются, отдельный контекст закрывается; основной 3D-контекст сохраняется. Учтена особенность асинхронной компиляции Three r164: её опрос безопасно прекращается при отмене/потере контекста.

Зависимости закреплены: three-gpu-pathtracer 0.0.23, three-mesh-bvh 0.8.0, Three 0.164.1. `vendor/browser-photo/engine-v47.js` собран локально, вспомогательные импорты включены; общий Three подключается через import map и используется также обычным режимом. Engine загружается только при первом нажатии «Фото». При временной ошибке модуля следующая попытка использует новый URL запроса.

## Проверки и ограничения

Chromium, настоящий WebGL 2 на SwiftShader и настоящий Rapier: фото/PNG/скачивание, полный счётчик проходов, раннее завершение, неизменность исходных материалов/позиций, возврат к исходной паузе/живой симуляции, Escape, повторный запуск, потеря фото-контекста без потери основного, неподдерживаемый float-буфер, неудачная загрузка и повтор модуля, импорт v45 без перезаписи. В сцене проверки есть цифра 8, звезда и прозрачный латекс. Все сетевые обращения фото — загрузка статических файлов; запросов к API вычислений нет.

Проверки состояний выполнялись с уменьшенными размерами изображения, но реальными 128/64 проходами. Калибровка света — 64 прохода на точной эталонной сцене; дополнительно реально рассчитан кадр 800×960 при 16 проходах и проверен фильтр на полном размере. Тесты на программном GPU не дают оценки скорости на телефоне. **Реальный iPhone/Safari, нативные GPU и пользовательская приёмка качества пока не проверены.** Это проба, не новый утверждённый стандарт.

## Откат и исходники

Опубликованная v45 сохраняется по `candysky-rapier-lab-1-v45-dark-oak-floor.html` с прежними байтами. Черновик v47 отдельный; v45 читается на копии. Изменения, сделанные только в v47, не записываются обратно в v45. Для v47 нужны HTML и vendor-файлы, открытие одного HTML через file:// не является поддерживаемым способом фото.

Исходники сборки: `engine-source.js`, `postprocess.js`, `photo-ui.js`, `package.json`, `package-lock.json`, `build.mjs`. Для пересборки: `npm ci && node build.mjs` из этой папки. Сборщик нужен разработчику, пользователю Test ничего устанавливать не нужно. Сведения о лицензиях — `vendor/browser-photo/THIRD-PARTY-LICENSES.txt`.
