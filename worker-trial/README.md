# CandySky — Worker, проба 2

Проба: https://mrmsmv.github.io/Test/worker-trial/
Обычная v56 для сравнения/отката: https://mrmsmv.github.io/Test/

Основной index и файлы v56/v55 не изменены. Сохранения пробы остаются в отдельной candysky-live-worker-trial-drafts, schema4.

Исправлено: потеря последней нижней длины при завершении подбора; индикатор пересечений теперь использует контакты Rapier; отказ worker отклоняет новые команды и позволяет перезагрузить последнюю сохранённую сцену. Быстрые изменения длины пересчитываются с последним значением; ручная отмена сохраняется.

Отображение: визуальные уровни детализации латекса, с исходной сеткой при выборе/приближении; физическая геометрия, массы, силы и калибровки v56 прежние. Кэш фактур очищает неиспользуемые наборы до бюджета 64 МиБ, сохраняя полное разрешение активных. Если активные наборы сами превышают бюджет, они сохраняются. На паузе без изменений нет постоянной отрисовки, камера и редактирование продолжают обновлять вид.

Локальная сверка четырёх баз и движений дала нулевые численные расхождения с v56. В проверенной сцене из 100 латексных шаров визуальная геометрия уменьшилась с ~6,65 млн до ~0,74 млн треугольников; это не оценка прироста FPS. Проверены замена, быстрые правки длины, отмена/удаление, кэш, сохранение/reload, отказ worker и восстановление. Сравнение скриншотов: вблизи исходная сетка совпала; в обычном масштабе отличия менее пикселя по расчётному допуску.

Проверки — Chromium/Linux. FPS, нагрев и длительная работа Safari/iPhone ещё требуют проверки на устройстве. Новая аэродинамика, массы и конфликтующие каталожные объёмы в эту пробу не включены.
