# CandySky · Фонтаны · v58

Уменьшено ожидание первой замены: расчётный worker готовится при открытии управления, выбранная фактура — при выборе товара. Число новых фактур, загружаемых заранее, ограничено двумя. Сцена меняется только после применения результата.

Если первоначальный вариант сложной сборки оказался неподходящим, раньше проверяется подходящая альтернативная стратегия. Успешный обычный первый вариант не требует дополнительного перебора. Холостая подготовка пропускается только при подтверждённом полном покое; перед продолжением подбора восстанавливается исходная подготовка. Модели, нормы лент, физическая точность и окончательная проверка переноса сохранены.

На одном контролируемом примере без памяти предыдущих решений поиск сократился с 26 до 15 с на компьютере. Это не обещание мгновенного пересчёта для любого состава и не замер iPhone: сложный полный поиск всё ещё может занимать время. Память удачных решений v57 сохранена.

До 4 фонтанов и 100 шаров. Проверены смешанные сцены, обратные замены, мобильный интерфейс, отмена/очередь, импорт v57 и сохранение100 объектов. У v58 отдельная база; исходная v57 не перезаписывается. Точная v57 оставлена для отката. Подробности — test-report-v58.json. Three.js/Rapier нужны с CDN, офлайн не готов.
