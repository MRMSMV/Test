# CandySky · Фонтаны · v59

Замена шара сразу меняет его настоящую геометрию, коллайдеры и ленту. Подбор окончательных длин и проверка сборки выполняются в фоне; редактор остаётся доступным. Новая замена отменяет устаревший расчёт. После замены шары естественно усаживаются; окончательное плотное равновесие не мгновенно.

Повторно используются точные формы контактных запросов Rapier. Модели, физические параметры, стандартные одноразмерные длины и полная проверка фоновых планов сохранены. Новых связей между шарами нет. Пока фактура декодируется, используется та же модель; карты присоединяются после загрузки. При нехватке места замена отклоняется до изменения сцены.

Проверены семь различных замен с настоящим движением, 16 стандартов, отмена старого выбора, две композиции, удаление, сохранение во время уточнения и перезагрузка. Сцена4×15+40 потолочных шаров=100 сохраняется и восстанавливается. Локальные замеры не являются замерами iPhone.

У v59 отдельная база черновиков с чтением v58 без записи в источник. Точная v58 оставлена для отката. Three.js и Rapier загружаются с CDN; офлайн не готов.
