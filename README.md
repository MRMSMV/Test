# CandySky 3D — v30: короткая верхняя лента, свободное движение

Текущая сборка: candysky-rapier-lab-1-v30-natural-top-ribbons.html, также MRMSMV/Test/main/index.html.

Для верхних латексных шаров 60 и 91,5 см лента теперь 50 см вместо 70/90. Нижняя лента по прежнему от 5 см, остальные верхние — 51 см. Внешний вид всех моделей прежний. В компактной спокойной сборке верхний шар прилегает к тройке, после движения шары могут естественно расходиться и соприкасаться. Никаких дополнительных связей между шарами нет. Под потолком 2,5 м нельзя гарантировать касание трёх: для компактной сборки уменьши нижнюю высоту.
