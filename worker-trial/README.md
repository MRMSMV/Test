# CandySky — Worker, проба 4

Проба: https://mrmsmv.github.io/Test/worker-trial/
Обычная v56 для сравнения/отката: https://mrmsmv.github.io/Test/

В пробе 4 убраны разгон, торможение, предел скорости и последующее догоняющее движение грузика. На ближайшем шаге физики грузик попадает в последнюю позицию указателя. Перенос обрабатывается как прямая смена положения, чтобы скачок кинематического тела не давал шарам огромный импульс.

Ограничение максимальной длины связей между ярусами из пробы 3 сохранено с допуском 0,1 мм; перед решением физики оно также согласует узлы с новой позицией грузика. Поворот и провисание связей остаются свободными, отдельных шаров между собой жёстко не связываем. У отдельного шара с грузиком при прямом переносе также предварительно ограничивается расстояние до точки крепления.

Основной index, v56/v55, модели, массы, подъёмные силы и заданные длины не изменены. Сохранения пробы остаются в отдельной candysky-live-worker-trial-drafts, schema4. Новая аэродинамика не включена.

Численные проверки четырёх баз 23/25/30/45 см и фонтана с цифрой 6: грузик достигает цели за один шаг, превышение длин соединителей не более 0,1 мм. Проверки Chromium/Linux не заменяют пользовательскую оценку управления на iPhone/Safari и не являются замером FPS.
